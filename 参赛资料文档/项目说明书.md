
# AI课题申报通知智能抓取与申报书自动生成系统
## 项目说明书（创新开发组）

## 一、项目概述
本项目面向公司各部门课题申报工作痛点，打造一套**全流程自动化AI工具**，实现：
- 自动爬取指定网站的课题申报通知
- AI智能解析申报核心信息
- 一键生成规范申报书文档
- 支持定时监控、实时提醒

解决人工查找慢、信息不全、撰写耗时、重复劳动等问题，大幅提升课题申报效率与质量。

## 二、业务背景与痛点
1. **信息分散**：课题通知分布在多个政府/高校/机构网站，人工查找耗时费力
2. **时效性差**：容易错过申报截止时间，错失项目机会
3. **撰写难度大**：申报书格式严格、内容专业，撰写周期长
4. **效率低下**：单份申报材料需1-2天，重复工作多

## 三、系统功能模块
### 1. 智能爬虫模块
- 支持多网站并行爬取
- 自适应网页结构，自动识别通知标题、时间、内容
- 每日定时自动执行，增量更新通知

### 2. AI分析模块
- 提取：申报方向、截止日期、主办单位、支持领域、申请条件、撰写要求
- 分类：按部门、领域、截止时间智能分类
- 摘要：生成通知核心要点速览

### 3. 申报书自动生成模块
- 内置标准申报模板
- AI根据通知要求自动填充、撰写正文
- 支持Word/PDF导出，格式合规
- 可手动编辑调整

### 4. Web可视化管理平台
- 通知列表查看
- 详情与AI分析结果展示
- 一键生成申报文件
- 任务配置与日志查看

## 四、技术架构
1. 前端：Streamlit（轻量化Web界面）
2. 爬虫：Requests + BeautifulSoup4 + Playwright
3. AI处理：LangChain + 大模型API
4. 文档生成：python-docx、ReportLab
5. 调度：APScheduler定时任务
6. 存储：本地文件/JSON，轻量无数据库依赖

## 五、创新点
1. **全流程自动化**：从信息获取到最终文档一键完成
2. **网站自适应**：一套爬虫框架适配多类通知页面
3. **AI深度赋能**：理解、抽取、撰写三位一体
4. **轻量化部署**：无需服务器，办公电脑即可运行
5. **高实用性**：直接解决部门高频痛点，可快速落地

## 六、应用效果
- 查找通知时间：从2小时/天 → 5分钟/天
- 申报书撰写：从1-2天 → 10分钟
- 信息准确率：≥95%
- 覆盖部门：全公司所有有课题申报需求的部门

## 七、落地可行性
1. **环境简单**：Python + 依赖包，一键安装
2. **成本极低**：无需硬件投入，免费开源组件
3. **使用门槛低**：界面简洁，员工10分钟上手
4. **安全合规**：仅爬取公开信息，不涉及涉密数据
5. **可维护性强**：模块化设计，易于扩展与更新
