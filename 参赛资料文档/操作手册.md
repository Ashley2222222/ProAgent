
# AI课题申报智能系统 —— 操作手册
## 快速上手（比赛演示版）

## 一、环境准备
1. 安装Python 3.10及以上版本
2. 解压项目压缩包
3. 打开命令行，进入项目目录
4. 执行安装命令：
   pip install -r requirements.txt

## 二、启动系统
1. 运行启动脚本：
   python web_app.py
2. 浏览器自动打开：http://localhost:8501
3. 进入系统主界面

## 三、核心功能操作
### 1. 爬取课题通知
- 点击左侧【开始爬取】
- 选择目标网站
- 等待爬取完成
- 查看最新通知列表

### 2. 查看AI分析结果
- 点击任意通知标题
- 查看AI提取的核心信息：
  ✅ 申报截止时间
  ✅ 申报领域与要求
  ✅ 重点支持方向
  ✅ 撰写要点提示

### 3. 一键生成申报书
- 点击【生成申报文件】
- 选择模板，填写基本信息
- AI自动撰写完整内容
- 点击【导出Word/PDF】保存文档

### 4. 定时任务设置
- 进入【任务配置】
- 设置每日爬取时间
- 系统自动后台运行
- 新增通知实时提示

## 四、比赛演示要点
1. 展示爬取结果 → 体现自动化
2. 展示AI分析页面 → 体现智能解析
3. 生成一份完整申报书 → 体现核心价值
4. 导出Word文档 → 体现实用性

## 五、常见问题
1. 爬取失败：检查网络，更换目标网站
2. 导出异常：确保安装依赖库完整
3. 界面卡顿：重启程序即可
