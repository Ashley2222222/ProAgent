# 更新日志

## [2026-03-11] 移除分析数量限制

### 功能改进

#### 1. 灵活的分析数量配置
- 新增 `LIMIT_NOTICES_PER_SITE` 配置选项
- 默认设置为 `False`，分析所有符合要求的通知
- 可选择性地限制数量，节省时间和token

#### 2. 优化配置逻辑
- 移除硬编码的数量限制
- 根据配置动态决定分析策略
- 添加明确的日志输出

### 配置更新

**config.py 更新：**

```python
# ========== 爬取配置 ==========

# 是否限制每个网站分析的通知数量
LIMIT_NOTICES_PER_SITE = False  # 默认：分析所有符合要求的通知

# 每个网站最多分析的通知数量（仅在 LIMIT_NOTICES_PER_SITE = True 时生效）
MAX_NOTICES_PER_SITE = 3
```

### 设计说明

**为什么默认分析所有通知？**

1. **双层过滤已足够**
   - 关键词过滤：只保留申报相关的通知
   - 日期范围过滤：只保留指定时间段的通知
   - 剩下的都是符合要求的通知，没必要再限制

2. **避免遗漏重要信息**
   - 限制数量可能会错过重要的申报通知
   - 通知数量通常不会太多，完全处理时间可接受

3. **灵活配置**
   - 如果某个网站通知特别多，可以临时开启限制
   - 满足不同场景的需求

### 使用场景

#### 场景1：分析所有符合要求的通知（推荐）

```python
# config.py
LIMIT_NOTICES_PER_SITE = False  # 分析所有符合要求的通知
```

**输出：**
```
  分析所有符合要求的通知: 14 条
```

#### 场景2：限制分析数量

```python
# config.py
LIMIT_NOTICES_PER_SITE = True   # 限制数量
MAX_NOTICES_PER_SITE = 3        # 每个网站最多分析3条
```

**输出：**
```
  限制分析数量: 前 3 条（共 14 条）
```

### 优势

1. ✅ **不会遗漏**：分析所有符合要求的通知，避免错过重要信息
2. ✅ **灵活配置**：可根据需要选择限制或全部分析
3. ✅ **清晰明确**：日志输出显示分析策略和数量
4. ✅ **节省资源**：需要时可以限制数量，节省时间和token

### 文件更新

- ✅ `config.py` - 新增 LIMIT_NOTICES_PER_SITE 配置
- ✅ `main.py` - 优化分析数量控制逻辑
- ✅ `README.md` - 更新配置说明
- ✅ `QUICKSTART.md` - 添加爬取数量说明

## [2026-03-11] AI分析过滤功能优化

### 新增功能

#### 1. AI分析智能过滤
- 新增 `AI_ONLY_ANALYZE_VALID` 配置选项
- 支持只对符合申报要求的通知进行AI分析
- 自动跳过不符合要求的通知，节省AI token消耗

#### 2. 明确的日志输出
- AI分析时显示通知是否符合要求
- 跳过AI分析时显示原因
- 统计AI分析和跳过的通知数量

### 配置更新

**config.py 新增配置项：**

```python
# AI分析过滤选项
AI_ONLY_ANALYZE_VALID = True
```

**说明：**
- `True`：只对符合要求的通知进行AI分析（推荐）
- `False`：对所有通知进行AI分析

### 符合要求的通知定义

符合要求的通知 = 包含申报类关键词 且 不包含排除关键词

**包含关键词：**
- 申报、智慧、人工智能、征集、申请、推荐、遴选、课题、项目、基金、指南、专项、计划

**排除关键词：**
- 公示、结果、批复、核准、批准、备案、奖励、验收、调研、考察、培训、会议等

### 使用示例

#### 示例1：只对符合要求的通知进行AI分析

```python
# config.py
ENABLE_AI_ANALYSIS = True
AI_ONLY_ANALYZE_VALID = True  # 推荐
MAX_NOTICES_PER_SITE = 3
```

**输出示例：**
```
[AI] 通知符合要求，开始AI分析...
[OK] AI分析完成:
   资助金额: 100万元
   截止日期: 2026-04-30
   ...
```

或

```
[SKIP] 通知不符合要求，跳过AI分析
        原因: 未包含申报关键词或包含排除关键词
```

#### 示例2：对所有通知进行AI分析

```python
# config.py
ENABLE_AI_ANALYSIS = True
AI_ONLY_ANALYZE_VALID = False  # 全局分析模式
MAX_NOTICES_PER_SITE = 3
```

**输出示例：**
```
[AI] 开始AI分析（全局模式）
[OK] AI分析完成:
   ...
```

### 文件更新

- ✅ `config.py` - 新增 AI_ONLY_ANALYZE_VALID 配置
- ✅ `main.py` - 优化AI分析逻辑，增加过滤功能

- ✅ `QUICKSTART.md` - 添加AI分析过滤说明

1. **节省成本**：只对有价值的通知进行AI分析，大幅降低token消耗
2. **提高效率**：跳过无关通知，专注于实际的申报通知
3. **灵活配置**：可根据需求选择过滤或全局分析
