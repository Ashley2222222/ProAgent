# 《项目申报建议书》初稿

## 一、项目基本信息
- **名称**：2026年广东省基础与应用基础研究基金项目
- **来源**：广东省基础与应用基础研究基金委员会
- **截止时间**：第一批项目申报截止时间未提及，第二批项目申报工作届时另行通知

## 二、核心申报条件
- 项目仅面向省基金依托单位（已经注册具备省基金项目申报资格的单位）申报。
- 每个申请人2026年只限提交1项省基金（包括省自然科学基金、省市联合基金、企业联合基金、行业联合基金）项目申请（包含第一批和第二批项目）。申请人申请和在研主持的省基金项目总数限2项。
- 申请人在研主持的省科技计划（专项、基金等）项目数达到3项（含）以上或逾期一年未验收的省科技计划（专项、基金等）项目数达到1项（含）以上的，不得申报。
- 申请人已经提交2项2026年度省科技计划（专项、基金等）项目申请的，不得申报。
- 因发生严重失信行为，被取消作为申报主体承担和参与省级科技计划任务资格的，不得申报。
- 除上述总体限制要求，其它各类型基金项目还有其他条件应一并满足，详见相应的申报指南（附件1~11）。

## 三、重点支持方向
- **第一批**：
    - 2027年度省自然科学基金。
    - 2026年度省市联合基金，包括粤穗联合基金、粤莞联合基金、粤惠联合基金、粤江联合基金、南沙联合基金。
    - 2026年度企业联合基金（公共卫生与医药健康领域），包括迈瑞医疗联合基金、智能医学影像融合创新联合基金。
    - 2026年度行业联合基金，包括气象联合基金、地质联合基金、水利联合基金。
- **第二批**：
    - 2026年度企业联合基金（公共卫生与医药健康领域），包括中卫科研联合基金（面向生物材料与临床重点疾病筛查诊断等领域，设置面上和重点两类项目）、万孚生物联合基金（面向体外诊断及检验医学领域，设置面上和重点两类项目）。

**申报切入点建议**：
- 对于省自然科学基金，可结合自身研究专长，选择具有创新性和前沿性的基础研究方向进行申报。
- 省市联合基金可关注当地的产业发展需求和特色，与当地的科研机构或企业合作，开展相关领域的研究。
- 企业联合基金（公共卫生与医药健康领域）可针对具体的企业需求和技术难题，开展应用基础研究或技术创新研究。
- 行业联合基金可结合行业发展趋势和热点问题，开展相关领域的基础研究或应用研究，为行业发展提供技术支持和理论基础。

## 四、申报材料清单检查表
- [ ] 依托单位科研诚信承诺函（承诺函模板可在申报系统开放后下载，由单位管理员在“申报管理”-“项目管理”-“省基金项目承诺函管理”中上传盖章后的扫描件）
- [ ] 合作研究协议（盖章扫描件，牵头依托单位和项目参与单位在申请书提交前签订，明确任务分工、资金分配、成果归属等情况，在网上申报系统中上传）
- [ ] 境外人员知情同意函（境外人员（非港澳人员）以个人身份参与项目申请时需上传，可在系统中下载模板的电子扫描文档）
- [ ] 申请人科研诚信承诺函（无须上传纸质承诺函，申请人在系统签订）
- [ ] 单位伦理委员会审查意见等相关证明（项目申请涉及科技伦理与科技安全等相关问题时需提供，以在附件中上传的审查意见等证明材料为准）

## 五、下一步行动建议
- **成立项目组**：尽快成立项目申报小组，明确小组成员的职责和分工，制定项目申报计划和时间表。
- **准备财务审计报告**：根据项目申报要求，准备近三年的财务审计报告，确保财务数据真实、准确、完整。
- **联系合作单位**：如需与其他单位合作，应尽快联系合作单位，商讨合作事宜，签订合作研究协议。
- **撰写申请书**：根据项目申报指南和要求，认真撰写申请书，确保申请书内容完整、逻辑清晰、重点突出。
- **审核申报材料**：在申报截止日期前，对申报材料进行认真审核，确保申报材料符合要求，无遗漏、无错误。
- **提交申报材料**：在申报截止日期前，将申报材料提交至广东省基础与应用基础研究基金委员会指定的申报系统。
- **跟踪申报进度**：提交申报材料后，及时跟踪申报进度，关注项目评审结果，如有需要，及时补充相关材料或进行答辩。
